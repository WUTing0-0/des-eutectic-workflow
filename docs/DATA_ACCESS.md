# Data access and third-party terms

The manuscript's Supplementary Information 1 contains methods and supporting figures. Supplementary Information 2 contains numerical support and candidate-level screening tables. Third-party experimental records and model checkpoints are not included in this clean public code repository.

## Upstream sources

- [3DG-MP](https://github.com/Hyanqing/3DG-MP): the repository includes an MIT software licence. That does not independently settle rights in every upstream experimental compilation.
- [Fajar eutectic diagrams](https://github.com/adroitfajar/eutectic-diagrams): source data are available upstream; the inspected repository did not contain an explicit redistribution licence. Obtain the data there and confirm terms with its authors before repackaging.
- [ILGen-ion](https://github.com/fate1997/ILGen-ion): its source notes identify several underlying databases, including the Cambridge Structural Database. Upstream database terms must be checked separately.
- [TabPFN v2.6](https://huggingface.co/Prior-Labs/tabpfn_2_6/blob/main/LICENSE): the model and outputs are subject to its non-commercial licence, including restrictions on hosted services. The MIT licence of this repository does not override those terms.
- Quantum-chemistry programs and third-party model weights must be obtained from their official distributors under the applicable licences.

The original code can be reviewed and downloaded without authentication. Complete raw-data regeneration requires obtaining the relevant upstream datasets and weights. The full compiled liquidus table still requires source-level redistribution clearance. The historical research repository is therefore kept private and is not presented as the public release.

Original derived data may be licensed under CC BY 4.0 only after confirming that no third-party terms constrain that asset. No such licence is applied by implication to all model predictions or experimental inputs.
